Google Apps Script URL 설정

구글 드라이브(구글 시트)로 취합 받으시려면, 구글 시트의 [확장 프로그램] ➔ [Apps Script]에서 웹 앱으로 배포한 URL을 아래에 입력하세요.

💡 Google Apps Script 예시 코드:

function doPost(e) {
  var sheet = SpreadsheetApp.getActiveSpreadsheet().getActiveSheet();
  var data = JSON.parse(e.postData.contents);
  sheet.appendRow([new Date(), data.studentName, data.dDay, JSON.stringify(data.scores), JSON.stringify(data.strategies), data.promises.join(', '), data.resolution]);
  return ContentService.createTextOutput("Success");
}
